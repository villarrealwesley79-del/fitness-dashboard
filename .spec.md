# Project Spec: fitness-dashboard
_Generated: 2026-02-19 08:00_

## What It Does
The Fitness Dashboard is a web application that allows users to track their fitness progress through various metrics including body measurements, workout logs, recovery data from an Oura ring API integration, and more.

## Tech Stack
- Language: Python 3.x
- Framework: Flask (version 3.1.2)
- Database: SQLite (for local storage), JSON files for persistence
- Key libs: pandas, openpyxl, gunicorn

## Entry Points
- `app.py` — main application file containing the server logic and API routes.

## File Structure
(key dirs/files):  
- `.env` — configuration variables like API keys.  
- `data_loader.py` — handles data parsing from logs and summaries.  
- `oura_client.py` — interacts with Oura API to fetch and store health metrics.
- `requirements.txt` — dependencies list.

## How to Run
```sh
gunicorn app:app -b 0.0.0.0:8000 --reload
```
